# Project Landing Page

The goal of this project is to make a full web page with a little bit of complexity,
this projects look intimidating because of many components like it has 4 sections
including a footer, but as long as you think about each sections as mini projects
then it kinda feels like manageable like building a lego piece by piece

The previous section realy helpful because the normal flow of document is not enough
to create custom nested layouts. Flexbox really saves you from the headache but pay
attention to how it behaves with respect to its properties

## Project takeaways

I try to refresh my skill and try new approaches like I try to structure my css like
a DOM tree so it is predictable you will know exactly where you want to edit a
selector, but the downside is there will be a lot of duplicate properties so I need
to tackle that in the future projects.

The previous lesson really helps in solving the problem, I used flexbox a lot and I'm
a bit confident on laying out elements having to know the core concepts and behavior
of like flex really helps a lot especially in decision making what properties are
suited for diffent kinds of scenario and what gets the job done easily
